# LB-02 — BibTeX export: plan

Spec: `docs/specs/2026-10-15-lb-02-bibtex.md`. TDD for everything in `src/lib/export`.

1. **Cite keys** — `src/lib/export/cite-key.ts` (+ `cite-key.test.ts`)
   - `asciiFold`, `familyName`, `citeKey(paper)`, `citeKeys(papers)`.
   - Tests:
     - the fixture names (`Underwood, Lydia`, `Schønning`, `Finserås`, Jr suffix, CJK)
     - stopwords, no year, no authors
     - collision suffixes don't depend on input order
     - all 20 fixture keys are unique and match `/^[a-z]+(\d{4}|nd)[a-z]+[b-z]?$/`
   - Check: `pnpm vitest run src/lib/export`.
2. **Code-built entries** — `src/lib/export/bibtex.ts` (+ test)
   - `escapeLatex`, `protectCase`, `buildEntry(paper, key)`.
   - Tests:
     - `@article` vs `@misc`
     - escaping `& % $ # _ { } ~ ^ \`
     - `{UK}`/`{COVID-19}` bracing
     - organisation authors braced
     - missing fields omitted
     - every fixture entry has balanced braces
   - Check: vitest.
3. **Re-keying fetched BibTeX** — `rekeyEntry(text, key)` in `bibtex.ts`
   - Tests:
     - a recorded single-line Crossref response
     - a multi-line DataCite-style response
     - HTML, empty text, two entries and unbalanced braces each return `null`
     - braces inside quoted values
   - Check: vitest.
4. **doi.org fetch + assembly** — `src/lib/export/doi.ts` (`normaliseDoi`, `fetchDoiBibtex`) and `src/lib/export/index.ts` (`bibtexFor`)
   - `fetch` is injected.
   - Tests:
     - the Accept header and URL encoding
     - non-200, non-BibTeX and oversized responses, a timeout and a thrown error all return `null`
     - at most 4 requests at once
     - mixed DOI and no-DOI papers, with the `fromDoi`/`built` counts
     - an empty library
   - Check: vitest.
5. **Route** — `src/app/api/export/[projectId]/route.ts`
   - Steps: parse `?format=` with `exportRequestSchema` and the id with `z.uuid()`, check the signed-in user (401), read the project (none gives 404), read the saved swipes joined to `papers(data)`, parse with `paperSchema`, dedupe, call `bibtexFor`, then return an attachment.
   - Non-bibtex formats still return 501 (LB-03).
   - Check: `pnpm check`, then curl it against local Supabase as the demo user (5 saved papers in the seed). doi.org is blocked in this sandbox, so expect every entry to be code-built here.
6. **Review + ship**
   - Run the `pr-reviewer` agent, fix its findings, run `pnpm check && pnpm build`, then ask before opening the PR.
