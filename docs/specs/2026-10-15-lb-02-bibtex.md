# LB-02 — BibTeX export

## Goal

Turn a project's saved papers into a correct `.bib` file. Every field comes from retrieved metadata (doi.org/Crossref or our `Paper` record), never from Claude. Every entry gets a stable, readable cite key (`lastnameYEARword`).

## User flow

The library page (LB-01) or a direct link calls `GET /api/export/<projectId>?format=bibtex`. A `<project-title>.bib` file downloads, with one entry per saved paper in cite-key order. LB-03 adds the other formats and the "copy `\cite{}`" button; both reuse the cite keys from here.

## Inputs / outputs

- **`citeKeys(papers) → Map<paperId, key>`** (pure)
  - Family name of the first author: the part before a comma if the name has one, otherwise the last word, skipping Jr/Sr/II/III. Folded to ASCII (`Schønning → schonning`, `Finserås → finseras`) and lowercased; `anon` if there is none.
  - Then the year, or `nd`.
  - Then the first title word that isn't a stopword, ASCII and lowercase; `untitled` if there is none.
  - Collisions: the paper with the smallest id keeps the bare key, and the rest get `b`, `c`, … (`boer2020social`, `boer2020socialb`). Keys don't depend on input order.
- **`buildEntry(paper, key) → string`** (pure, the code-built fallback)
  - `@article` when there is a venue (`journal = {venue}`), otherwise `@misc`.
  - Fields: `author` (names joined with `and`), `title`, `journal`, `year`, `doi`, `url`. Missing fields are left out, never written as "not stated".
  - LaTeX specials (`& % $ # _ { } ~ ^ \`) are escaped. Words with inner capitals or all caps (`UK`, `COVID-19`, `iPhone`) are braced so styles keep their case.
  - Author names that look like organisations (`Group`, `Consortium`, `Organization`, …) are wrapped in braces.
  - Non-ASCII text stays UTF-8 (fine for biber and for modern bibtex with `inputenc`).
- **`rekeyEntry(text, key) → string | null`** (pure)
  - Accepts exactly one well-formed `@type{key, … }` entry with balanced braces, replaces its key, trims it and puts one field per line.
  - Returns `null` for anything else, such as HTML, empty text, several entries or unbalanced braces.
- **`fetchDoiBibtex(doi, { fetch, signal })`**
  - `GET https://doi.org/<doi>` with `Accept: application/x-bibtex; charset=utf-8`.
  - A 5 s timeout, following redirects, and responses capped at 64 KB.
  - Returns the text, or `null` on any failure. It never throws.
- **`bibtexFor(papers, { fetch })`** (server)
  - Looks up DOI papers (at most 4 at a time) and runs each result through `rekeyEntry`. When the fetch or the check fails, it uses `buildEntry` instead. Papers with no DOI go straight to `buildEntry`.
  - Returns `{ text, fromDoi, built }`.
- **Route:** `format=bibtex` reads the saved papers as the signed-in user (RLS), i.e. papers any member saved and whose latest decision is still `save`.
  - Success: `200 text/x-bibtex` with `Content-Disposition: attachment; filename="<slug>.bib"`.
  - Errors: `400` (bad id or format), `401`, `403`/`404` (not a member, so RLS returns no project), `500`.
  - The other formats keep returning `501` until LB-03.

## Edge cases

- **Names:** names already written "Last, First" (`Underwood, Lydia`); CJK or empty names give `anon`; papers with no authors are written without an `author` field.
- **Fallbacks:** a DOI that doi.org doesn't know (404) or answers with HTML falls back to `buildEntry`. A DOI with a different case or a `https://doi.org/` prefix is normalised before fetching.
- **Crossref output:** comes back as one line with a leading space and its own key (`Boer_2020`). It is re-keyed so `\cite{}` matches LB-03.
- **Empty library:** a valid empty file (a comment header only), not an error.

## Out of scope

- Other formats and the UI buttons (LB-03); the library page (LB-01).
- Caching fetched BibTeX in the database (it would need a migration).
- Fetching BibTeX for papers without a DOI.
